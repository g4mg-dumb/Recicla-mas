t# Manual de Usuario

## Nombre de la aplicación

**♻️ Recicla+**

---

## Propósito

Recicla+ es una aplicación móvil desarrollada para facilitar el reciclaje mediante la identificación de residuos a través de una fotografía. La aplicación informa el tipo de material detectado, el color del contenedor correspondiente y la forma correcta de depositarlo. Además, proporciona información educativa sobre reciclaje y muestra puntos de reciclaje utilizando Google Maps.

---

## Requisitos

- Dispositivo con sistema operativo Android.
- Cámara funcional.
- Conexión a internet
- Permisos de cámara habilitados para la app.

---

## Cómo iniciar la aplicación

1. Instalar y abrir la aplicación **Recicla+**.
2. Conceder los permisos solicitados (cámara y ubicación).
3. Seleccionar la opción que desea utilizar desde la pantalla principal.

---

## Funciones principales

### 📷 Escanear residuo

Permite tomar una fotografía de un objeto para identificar el tipo de residuo que es y conocer la manera adecuada de reciclarlo.

### ♻️ Ver resultado del análisis

Muestra el material detectado, el color del contenedor correspondiente y las recomendaciones para desechar correctamente el residuo.

### 🗺️ Consultar puntos de reciclaje

Permite visualizar en un mapa los puntos de reciclaje disponibles para facilitar la correcta disposición de los residuos.

### ℹ️ Consultar información

Proporciona instrucciones de uso de la aplicación e información general sobre reciclaje, separación de residuos y el impacto que genera en el medioambiente.

---

## Mensajes frecuentes

| Mensaje | Significado | Acción recomendada |
|---|---|---|
| Residuo identificado correctamente. | El objeto fue reconocido por la aplicación. | Revisar la información mostrada. |
| No se pudo identificar el residuo. | La imagen no pudo analizarse correctamente. | Tomar una nueva fotografía con mejor iluminación. |
| Permita el acceso a la cámara. | La aplicación no tiene permisos para usar la cámara. | Habilitar el permiso desde la configuración del dispositivo. |
---

## Problemas frecuentes

| Problema | Solución |
|---|---|
| La cámara no funciona. | Verificar que la aplicación tenga permisos para utilizar la cámara. |
| El objeto no se logra reconocer. | Asegúrese de enfocar correctamente el objeto y de que sea el único elemento visible en la imagen. Procure tomar la fotografía con buena iluminación. |
| El mapa no muestra los puntos de reciclaje. | Comprobar la conexión a Internet y que la ubicación esté activada. |
| La aplicación responde lentamente. | Cerrar otras aplicaciones y reiniciar Recicla+. |
| La pantalla queda completamente blanca y la aplicación deja de responder. | Cierre completamente la aplicación y vuelva a abrirla.
